# JLPT N2 备考资料

这是 Obsidian 笔记库。`JLPT N2/00 开始这里.md` 是学习入口，`资料/N2真题/` 保存试卷、解析与音频；笔记中的试卷链接均指向库内文件。

## 在另一台电脑使用

1. 安装 Git 和 Git LFS，并运行 `git lfs install`。
2. 克隆本仓库，确认 PDF 和 MP3 已下载，而不是只有 LFS 指针文件。
3. 在 Obsidian 中将克隆目录作为库打开。
4. 修改后先拉取远端更新，再提交并推送。不要同时在两台电脑修改同一篇笔记。

## 在这台电脑同步

在 Finder 中双击 `同步到 GitHub.command`。脚本会提交本地改动、拉取远端更新并推送；如果出现合并冲突，会停止并显示错误，需要先解决冲突再重新运行。

`.obsidian/workspace.json` 是本机窗口状态，未纳入版本控制。现有 `LICENSE` 仅用于本仓库原创笔记；试卷、解析和音频的权利归原权利人，不能从该许可推断这些资料可再许可。
