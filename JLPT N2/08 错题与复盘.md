## 错因代码

| 代码 | 含义 | 下一步 |
|---|---|---|
| V | 词读音、字形或词义不熟 | 查 [[03 真题词汇]]，写一个搭配 |
| C | 词语搭配／用法错误 | 同时写正确和不自然的搭配 |
| G | 语法关系或接续错误 | 查 [[04 语法地图]]，写易混对照 |
| R | 阅读依据没找到／误读限定 | 标原文证据和选项偷换处 |
| L | 听漏、跟不上、误判最终决定 | 用原音与原文做三遍复盘 |
| T | 时间分配失误 | 记录本题用时，调整下一套卷策略 |
| S | 粗心或涂卡错误 | 记录触发情境，最后检查 |

## 单题模板

```markdown
### 年月 · 科目 · 题号
- 首做日期：
- 我的选择／正确选择：
- 错因代码：
- 原文依据或关键搭配：
- 为什么正确：
- 另外三项为什么不合适：
- 可迁移知识：
- 次日复做：[ ]  7 日复做：[ ]  21 日复做：[ ]
```

## 每周复盘

```markdown
### 第 __ 周（日期）
- 完成的卷与模块：
- 错因最多的前三类：
- 本周真正掌握的词／语法：
- 阅读最常误判的证据：
- 听力最常漏掉的信息：
- 下周每天调整的 30 分钟：
```

错题复做时遮住答案，**能解释正确项和干扰项**才勾选。连续两次答对、间隔至少 7 天，才从高频复习清单移走。
