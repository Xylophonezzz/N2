# 语法地图 · 按句子关系选形式

先找 **关系**（时间、条件、逆接、范围、推量等），再检查 **接续** 与说话人的立场。表中“真题”表示该结构或功能在所标题中出现；“延伸”是同类必辨结构，并非历年出现次数统计。例句为复习用自拟短句。

## 1. 时间、变化、阶段

| 结构 | 接续与意义 | 例句 | 来源 |
|---|---|---|---|
| ～ぶりに | 时间名词＋ぶりに；隔了……之后再次 | 3年ぶりに友人に会った。 | 2020.12 Q31、2023.07 Q38 |
| ～たびに | V辞书形／Nの＋たびに；每当 | この曲を聞くたびに故郷を思い出す。 | 延伸 |
| ～につれて | V辞书形／N＋につれて；随着一方变化，另一方也变化 | 年を取るにつれて考え方が変わる。 | 2023.07 Q31 |
| ～に伴って | V辞书形／N＋に伴って；伴随、较正式 | 人口の増加に伴って交通量も増えた。 | 延伸 |
| ～に従って | V辞书形／N＋に従って；随变化或按指示 | 説明に従って操作する。 | 延伸 |
| ～かけ | Vます形去ます＋かけ；做到一半 | 読みかけの本を机に置いた。 | 2022.12 Q31 |
| ～きり | Vた形＋きり；自从……后再没有 | 家を出たきり連絡がない。 | 2026.07 Q45 语序 |
| ～ないうちに | Vない形＋うちに；趁还未…… | 忘れないうちにメモする。 | 2025.12 Q32 关联表达 |
| ～てからでないと | Vて形＋からでないと；不先做前项就不能做后项 | 予約してからでないと入れません。 | 2024.12 Q34 |
| ～に向けて | N＋に向けて；朝向目标 | 完成に向けて準備を進める。 | 2022.12 Q33 |

**易混**：「につれて」强调两个变化同步；「に伴って」更书面，变化可涉及社会现象；「に従って」还可表示“遵照指示”。「うちに」是某状态持续期间，「ないうちに」是状态尚未发生之前。

## 2. 条件、假设、决定

| 结构 | 接续与意义 | 例句 | 来源 |
|---|---|---|---|
| ～ものなら | V可能形＋ものなら；如果真能……（通常难以实现） | 戻れるものなら、あの日に戻りたい。 | 2026.07 Q34 |
| ～からには | 普通形＋からには；既然已决定，就承担后续 | 引き受けたからには最後までやる。 | 2025.12 Q34 |
| ～ばいい | Vば形＋いい；……就好 | 分からなければ聞けばいい。 | 2026.07 Q40 |
| ～と | V辞书形＋と；规律或必然结果 | 春になると花が咲く。 | 2026.07 Q43 语序 |
| ～たところ | Vた形＋ところ；做了后发现结果 | 調べたところ、予約が必要だった。 | 延伸 |
| ～限り | N／普通形＋限り；仅限范围，或只要…… | 本日に限り入場無料です。 | 2025.12 Q33 |
| ～に際して | N／V辞书形＋に際して；在重要场合之际 | 入学に際して書類を提出する。 | 2026.07 Q35 干扰项 |
| ～にあたって | N／V辞书形＋にあたって；在开始某事时 | 建設にあたって住民に説明する。 | 2025.07 Q31 |

**易混**：「ものなら」常含实现困难的愿望或警告；「からには」前项已成事实；「ばいい」给建议。「に際して」与「にあたって」都正式，后者更常接开展具体行动、准备。

## 3. 逆接、对比、强调

| 结构 | 接续与意义 | 例句 | 来源 |
|---|---|---|---|
| ～ながらも | Vます形去ます／形容词／N＋ながらも；虽……却…… | 忙しいながらも毎日練習する。 | 2025.07 Q32 |
| ～ようでいて | 普通形＋ようでいて；看似……其实…… | 簡単なようでいて難しい。 | 2020.12 Q36 |
| ～だけでなく | 普通形／N＋だけでなく；不但……而且…… | 体だけでなく心も強くなった。 | 2026.07 Q37 |
| ～どころか | 普通形／N＋どころか；岂止……反而…… | 雨がやむどころか、強くなった。 | 2021.07 Q31 干扰关系；延伸用法 |
| ～とはいえ | 普通形＋とはいえ；虽说……但…… | 安いとはいえ、必要ないものは買わない。 | 2023.07 Q31 干扰项 |
| ～ものの | 普通形＋ものの；虽……却……，较书面 | 応募したものの、自信がない。 | 2023.07 Q33 |
| ～一方で | 普通形／Nである＋一方で；另一方面 | 便利な一方で、費用が高い。 | 2026.07 Q49 文章语法关联 |
| ～に至っては | N＋に至っては；举出更极端的例子 | 兄は料理が苦手で、父に至っては包丁も使えない。 | 2023.12 Q31 |
| ～にしては | N／普通形＋にしては；以……而言却意外 | 初めてにしては上手だ。 | 2023.12 Q31 干扰项 |
| ～なんか | N＋なんか；轻视或谦逊地举例，口语 | 私なんか、まだまだです。 | 2024.07 Q31 |
| ～さえ | N＋さえ；连……都…… | 水に顔をつけることさえできなかった。 | 2024.12 Q31 |
| ～すら | N＋すら；连……都……，较书面 | 名前すら覚えていない。 | 2021.07 Q31 |

**易混**：「だけでなく」平稳追加，「どころか」后项往往推翻或超出前项；「ものの／とはいえ」均逆接，前者常交代未如预期的结果，后者更像让步。

## 4. 范围、依据、方式

| 结构 | 接续与意义 | 例句 | 来源 |
|---|---|---|---|
| ～とは | N＋とは；下定义“所谓……” | 年賀状とは、新年の挨拶を送るはがきのことだ。 | 2026.07 Q31 |
| ～でしか～ない | N＋でしか＋否定；只以某种状态、手段 | この野菜は生でしか食べたことがない。 | 2026.07 Q33 |
| ～に沿って | N＋に沿って；沿着、按照方针 | テーマに沿って資料を集める。 | 2026.07 Q35 |
| ～に対して | N＋に対して；对比或针对 | 100グラムに対して砂糖を80グラム使う。 | 2024.12 Q33 |
| ～を問わず | N＋を問わず；不问、不论 | 経験を問わず参加できます。 | 2021.07 Q33 |
| ～にかかわらず | N＋にかかわらず；不受……影响 | 参加の有無にかかわらず読んでください。 | 2023.12 Q32 |
| ～抜きで | N＋抜きで；省略、不带 | 朝食抜きで出かけた。 | 2025.12 Q31 |
| ～によって | N＋によって；原因、手段、依据或个体差异 | 方法は人によって違う。 | 2026.07 Q43 关联表达 |
| ～に応じて | N＋に応じて；根据变化调整 | 必要に応じて休憩する。 | 延伸 |
| ～を通じて | N＋を通じて；通过、贯穿一段时间 | 仕事を通じて学んだ。 | 延伸 |

**易混**：「に沿って」遵循路线、主题或方针；「に応じて」根据条件调整；「に対して」是面向对象，也可表示比例，不等于「について」（关于）。

## 5. 推量、可能、心理与义务

| 结构 | 接续与意义 | 例句 | 来源 |
|---|---|---|---|
| ～かねる | Vます形去ます＋かねる；难以、不能（常用于婉拒） | その質問には答えかねます。 | 2020.12 Q39 |
| ～かねない | Vます形去ます＋かねない；恐怕会有坏结果 | このままでは事故が起こりかねない。 | 2026.07 Q38 干扰项 |
| ～ずにはいられない | Vない形去ない＋ずにはいられない；忍不住 | 気になって調べずにはいられない。 | 2026.07 Q41 |
| ～はずがない | 普通形＋はずがない；有依据地否定可能 | 銀行が電話で暗証番号を教えるはずがない。 | 2026.07 Q42 |
| ～はずだ | 普通形＋はずだ；有依据的预期 | 今出れば間に合うはずだ。 | 2026.07 Q51 文章语法 |
| ～そうにない | Vます形去ます＋そうにない；看起来不可能 | 一人では食べ切れそうにない。 | 2024.12 Q41 关联表达 |
| ～してはならない | Vて形＋はならない；禁止 | ここで写真を撮ってはならない。 | 2026.07 Q38 |
| ～ように言われる | V辞书形／ない形＋ように言われる；被要求做／不做 | 先に読んでおくように言われた。 | 2026.07 Q36 |
| ～ざるを得ない | Vない形去ない＋ざるを得ない；不得不 | 予定を変更せざるを得ない。 | 2020.12 Q39 干扰项；延伸用法 |
| ～わけではない | 普通形＋わけではない；并非全然如此 | 嫌いなわけではない。 | 延伸 |
| ～にすぎない | 普通形／N＋にすぎない；只不过 | これは一例にすぎない。 | 2020.12 Q39 干扰项；延伸用法 |

**易混**：「かねる」是说话人难以做；「かねない」是负面可能性，两者方向相反。「はずだ／はずがない」都有依据；「そうだ」偏眼前样态。敬语另记「承る（うけたまわる）」为「受ける／聞く」的自谦语，2026.07 Q39。

## 6. 语序题先找固定组合

- 「～ようにしている」＝持续努力；2026.07 Q44。例：朝はなるべく食べるようにしている。
- 「～だけで済ませる」＝只用……解决；2026.07 Q44。例：昼食をパンだけで済ませた。
- 「～たきり、～ない」＝之后再没……；2026.07 Q45。
- 「～たまま」＝维持状态；2026.07 Q45。
- 「～によるものだ」＝由……所致；2026.07 Q43。
- 「～か分からないぐらい」＝多到不知多少；2026.07 Q46。

语序题按 **接续 → 固定搭配 → 句子关系** 排列，再检查星号位置；不要先猜整句中文。关联复习：[[06 考前速查]]、[[07 主动回忆卡片]]。
