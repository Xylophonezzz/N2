## 文字与词汇：从读音转向搭配

| 题 | 关键辨析 | 为什么值得记 |
|---|---|---|
| Q1-5 | 濃い（こい）、競技（きょうぎ）、消毒（しょうどく）、構う（かまう）、知人（ちじん） | 同一题组既有音读复合词，也有训读动词；不要只背汉字读音。 |
| Q6-10 | 睡眠、資源、補う、説教、鮮やか | 汉字题常用形近字干扰；「補う」是补充不足，「捕う」不是这个词。 |
| Q11-13 | 各グループ、大統領制、卵大 | 构词要背成词组。「各」后接单位，「～制」表示制度，「卵大」表示鸡蛋大小。 |
| Q14-20 | 判断する、日程の調整、赤字を出す、おおざっぱ、たくましく、話がそれる | 选择题需要宾语和固定搭配；只知道中文大意仍可能误选。 |
| Q21-25 | メーカー、一括、思いがけない、いっそう | 近义替换看整句话：メーカー＝制造商；一括＝合并在一起；思いがけない＝未预料；いっそう＝更加。 |
| Q26-30 | 要点、裂ける、経過、打ち消す、さっと | 词语使用题看“典型宾语”：要点を説明する、布が裂ける、時間が経過する、うわさを打ち消す、顔色がさっと変わる。 |

**重点复现**：「鮮やか」同时出现在 2020.12、2024.07、2026.07；它可能考汉字，也可能考读音。把词汇的**字形、读音、义项、搭配**绑在一起记。

## 句子语法 Q31-42

| 题 | 判定线索 | 正确结构／要避开的误区 |
|---|---|---|
| Q31 | 后面是在定义年贺状 | 「～とは」给定义；「～としては」是“作为……而言”。 |
| Q32 | 竟像到误认自己的照片 | 「あまりにも」表示程度过高；「ちっとも」须配否定。 |
| Q33 | 过去只以生食形式吃黄瓜 | 「生でしか～ない」；状态用「で」，「しか」后接否定。 |
| Q34 | 想替生病的儿子承受，但实际上做不到 | 可能形＋「ものなら」表示难实现的假设。 |
| Q35 | 按自己选的主题收集资料 | 「テーマに沿って」；「に伴って」表示伴随变化。 |
| Q36 | 老师要求提前读书 | 「読んでおくように言われた」；间接命令用「ように」。 |
| Q37 | 身体和精神都变强 | 「丈夫になっただけでなく」；注意「丈夫に**なる**」搭配。 |
| Q38 | 拳击规则禁止攻击背部 | 「攻撃してはならない」；与「しきれない」「しかねない」功能不同。 |
| Q39 | 酒店员工接受客人的预订 | 「承ります」是说自己行为的自谦语；「なさいます」是说对方的尊他语。 |
| Q40 | 找不到理想桌子，就自己做 | 「作ってしまえばいい」表达“做了就好”。 |
| Q41 | 有疑问便控制不住去查 | 「調べずにはいられない」。 |
| Q42 | 银行不可能电话告知密码 | 「教えてくれるはずがない」，同时检查授受方向。 |

复盘顺序：先辨语义关系，再看接续，再看主语与敬语方向。完整接续见 [[04 语法地图]]。

## 语序与文章语法 Q43-51

- Q43：把「汗をかくと」和「体温が下がる」连成规律，再接「その性質によるもの」说明原因。
- Q44：识别「食べるようにしている」与「牛乳だけで済ませる」两个固定组合；转折后是时间不够。
- Q45：「入っていったきり」引出“再没出来”；「出てこないまま」保持状态。
- Q48-51：在段落里区分不定指「ある」、对比「一方」、解释「というのは」、有依据的预期「はずだ」。文章语法题必须连读前后句，不能孤立选词。

## 阅读与听力的高价值题

- Q53 搬家邮件：追加搬运事项与取消电视设置是**两个同时成立的条件**。
- Q55 工作邮件：已完成、待修正、对方下一步是三种时间状态；问“先做什么”时先排除未来事项。
- Q70-71 食谱通知：资格、材料、时间、费用、提交方式都可能成为排除条件。把每个条件打勾再选。
- 听力问题 1：女性先准备留言卡，取礼物是两三周后的事；“谁做、何时做”比单听见任务名更重要。
